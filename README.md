# Urban Wheels 41

Лендинг автопроката **Urban Wheels 41** (Петропавловск-Камчатский).

Next.js 14 (App Router) · TypeScript · Tailwind CSS · одна страница · деплой на Vercel.

## Запуск

```bash
npm install
npm run dev
```

Открыть http://localhost:3000

```bash
npm run build && npm run start   # продакшен-сборка
npm run lint
```

## Что где правится

Весь контент вынесен в `/data` — верстку трогать не нужно.

| Файл | Что содержит |
| --- | --- |
| `data/cars.ts` | Автопарк: название, фото, характеристики, категория (`sedan` / `suv`). Категория определяет таб в секции «Автомобили» |
| `data/reviews.ts` | Отзывы с Яндекс Карт (сейчас заглушки из макета) |
| `data/site.ts` | Телефон, адрес, режим работы, навигация, тексты hero / преимуществ / «Почему выбирают нас» / футера |

Телефон меняется в одном месте — `contacts.phone` (отображение) и `contacts.phoneHref` (ссылка `tel:`).
На него ведут все кнопки на странице.

### Добавить автомобиль

Дописать объект в массив `cars` в `data/cars.ts`, положить фото в `public/images/`
и указать реальные `width` / `height` файла — карточка появится в нужном табе сама.

## Структура

```
app/
  layout.tsx        шрифты (Oswald + Manrope, кириллица), метатеги, og:image
  page.tsx          сборка секций + JSON-LD разметка организации
  icon.png          фавиконка (диск из логотипа)
components/
  header.tsx        sticky-шапка с blur, бургер-меню до 1024px
  hero.tsx          баннер, градиенты под текст (свои для мобилы и десктопа)
  advantages.tsx    4 карточки преимуществ
  cars-section.tsx  табы «Легковые» / «Внедорожники» + сетка карточек
  benefits.tsx      «Почему выбирают нас»
  reviews-carousel.tsx  карусель отзывов со стрелками и точками
  footer.tsx        контакты + статичная карта-ссылка
  icons.tsx         инлайновые SVG-иконки с золотым градиентом
data/               контент (см. выше)
public/images/      ассеты
```

## Дизайн

- Фон `#0A0A0A`, карточки `#141414`, границы `#262626`
- Акцент — золотой градиент `#E0B84C → #C9A227` (иконки, подчёркивания, кнопки)
- Текст `#FFFFFF`, вторичный `#A0A0A0`
- Oswald — заголовки (всегда UPPERCASE), Manrope — остальной текст
- Mobile-first, брейкпоинты `640 / 1024 / 1280` (переопределены в `tailwind.config.ts`)

## Заметки

- `public/images/mockup.png` — исходный макет, лежит для справки, на странице не используется.
- Карта в футере — статичная картинка со ссылкой на Яндекс Карты. Без iframe и без Maps API.
- Формы бронирования, календаря и онлайн-оплаты нет — все CTA ведут на телефон.
- Соцсетей на странице нет.
- `sharp` в зависимостях — ускоряет оптимизацию картинок `next/image` локально;
  на Vercel используется встроенная оптимизация.

## Деплой

Проект деплоится на Vercel из этого репозитория без дополнительной настройки:
Framework Preset — Next.js, build command и output определяются автоматически.
